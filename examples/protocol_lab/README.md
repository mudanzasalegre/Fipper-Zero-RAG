# Synthetic input fixtures (NOT real captures)

All example values are intentionally synthetic and contain no real tags, access credentials, captured wireless traffic, or operational attack sequences. These files demonstrate the *structural syntax* of supported formats; they are not intended for hardware use or signal transmission. The laboratory does not send them to a Flipper device.

```
flipper-rag lab batch --directory examples/protocol_lab
flipper-rag lab analyze --file examples/protocol_lab/demo-ir.ir --report markdown
```
