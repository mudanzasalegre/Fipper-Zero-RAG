# JavaScript en Flipper Zero

El firmware proporciona un entorno de scripting JavaScript para determinados módulos y operaciones. Las APIs disponibles, nombres de módulos y capacidades de ejecución dependen del firmware: se deben comprobar en la documentación de JS y en el código de la revisión concreta. No trasladar automáticamente ejemplos de Node.js o navegador al intérprete del dispositivo.

Referencias: https://developer.flipper.net/flipperzero/doxygen/js.html ; https://developer.flipper.net/flipperzero/doxygen/js_using_js_modules.html
