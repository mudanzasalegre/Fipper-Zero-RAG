# Aplicaciones FAP, manifiestos y uFBT

Una aplicación externa Flipper Application Package (FAP) suele compilarse en C/C++ y ejecutarse desde microSD. El manifiesto de la app define metadatos y dependencias. Para desarrollar una aplicación sin compilar todo el firmware es adecuado comenzar con uFBT, la herramienta simplificada oficial. La compilación está relacionada con la API disponible en el SDK y la versión de firmware: comprobar compatibilidad.

El catálogo oficial aloja manifiestos y metadatos de aplicaciones comunitarias, pero no todo su código fuente. Para estudiar el código real, seguir el enlace al repositorio específico y comprobar su licencia. Las APIs de Furi se documentan en Developer Docs.

Referencias: https://developer.flipper.net/flipperzero/doxygen/applications.html ; https://github.com/flipperdevices/flipperzero-ufbt ; https://github.com/flipperdevices/flipper-application-catalog
