# Furi API y Flipper Build Tool

Furi proporciona servicios del sistema operativo para tareas, sincronización, memoria, registros y comunicación entre componentes. Consultar encabezados y ejemplos del commit exacto de firmware. FBT es un sistema de construcción de firmware basado en SCons que se ejecuta desde el árbol del firmware; no es lo mismo que uFBT.

Comandos de referencia documentados por el fabricante: `./fbt` para construir, `./fbt fap_<appid>` para una app determinada y `./fbt cli` para abrir consola CLI (consultar las restricciones y requisitos de cada entorno). Una operación de flashing exige verificación de versión y copia de seguridad previa.

Referencias: https://developer.flipper.net/flipperzero/doxygen/fbt.html ; https://developer.flipper.net/flipperzero/doxygen/app_dev_furi_api.html
