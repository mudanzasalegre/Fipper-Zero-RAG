# Buenas prácticas para investigación con Flipper Zero

## Autorización

Realiza pruebas de radio, tarjetas, etiquetas y accesos únicamente sobre equipos propios o con permiso explícito. No confundas la capacidad de leer o emular algunos formatos con autorización para utilizarlos en sistemas de acceso. Las frecuencias permitidas para transmisión y los límites de potencia dependen de la jurisdicción y del firmware.

## Calidad de las respuestas RAG

Una respuesta técnica válida debe citar el documento y, cuando sea posible, el commit o versión del firmware. Documentación de terceros no equivale a funcionalidad soportada oficialmente. Las fuentes pueden quedarse obsoletas: sincroniza el índice, registra la revisión y verifica la API actual antes de compilar.
