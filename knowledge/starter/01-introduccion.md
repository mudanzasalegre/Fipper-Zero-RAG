# ¿Qué es Flipper Zero?

Flipper Zero es una plataforma portátil para experimentar con interfaces digitales y protocolos de comunicación, especialmente en entornos propios o autorizados. Combina funciones de radio Sub-GHz, NFC de 13,56 MHz, RFID de baja frecuencia (125 kHz), infrarrojos, iButton, Bluetooth LE, USB y GPIO.

Las características específicas, los protocolos compatibles y las restricciones regionales deben comprobarse en el manual del modelo y firmware concretos: https://docs.flipper.net/zero y https://docs.flipper.net/zero/development/hardware/tech-specs.

## ¿Dónde está el firmware?

Código fuente oficial: https://github.com/flipperdevices/flipperzero-firmware. La documentación de desarrollo está en https://developer.flipper.net/flipperzero/doxygen/. El código del firmware y muchos de sus componentes se distribuyen bajo GPL-3.0; consulta los avisos de terceros y la licencia de cada repositorio antes de redistribuirlos.

## Apps de usuario

Las aplicaciones externas suelen distribuirse como archivos FAP y se desarrollan mediante uFBT. JavaScript también está soportado en el firmware; para detalles específicos de módulos y APIs consulta el sitio de desarrolladores.
