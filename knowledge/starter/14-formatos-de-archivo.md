# Formatos de archivos del dispositivo

La documentación del desarrollador incluye formatos para señales Sub-GHz, NFC, RFID de baja frecuencia, infrarrojos, iButton, BadUSB y otros datos. Las extensiones indican clases de archivo, no autorizan su uso sobre sistemas ajenos. Para una explicación precisa, citar la especificación por nombre y versión, porque campos y codificaciones pueden evolucionar.

No indexar copias de llaves, capturas de radio privadas, archivos de credenciales ni colecciones de códigos de terceros. El proyecto indexa documentos técnicos y código autorizado.

Referencias: https://developer.flipper.net/flipperzero/doxygen/file_formats.html
